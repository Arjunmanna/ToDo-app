# 📝 React Todo List

## 📖 Overview
A simple and responsive Todo List application built with **React.js** and **Bootstrap**.  
This project demonstrates core React concepts like **state management, props, and hooks**.

---

## ✨ Features
- Add new tasks  
- Edit existing tasks  
- Remove tasks  
- Responsive Bootstrap-based design  
- Interactive UI with React hooks  

---

## 🛠️ Tech Stack
- React.js  
- Bootstrap  
- CSS
